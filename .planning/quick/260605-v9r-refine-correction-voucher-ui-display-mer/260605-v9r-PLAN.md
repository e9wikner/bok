# Plan

## Problem
When a user makes a correction to a posted voucher, the B-series correction voucher appears as a separate item in the vouchers list and as a separate page. The user wants the correction to be visualized as part of the original voucher, showing what changed and what the net result is.

## Changes

### Backend
1. **api/routes/vouchers.py**: Include `original_data` and `corrected_data` in the `_correction_chain_for_voucher` response so the frontend has the row-level data needed to compute net and diff views.

### Frontend
1. **lib/api.ts**: Update `VoucherSourceContext.correction_chain` type to include `original_data` and `corrected_data` fields.
2. **app/vouchers/page.tsx**: Exclude B-series (`"IB,B"`) from the vouchers list so correction vouchers don't appear as separate rows.
3. **app/vouchers/[id]/page.tsx**:
   - Add `rowView` state ("original" | "net" | "diff") for tab switching
   - Show a banner when viewing a B-series correction voucher, linking to the original
   - Show a "corrected" banner on original vouchers that have corrections
   - In the rows card, add tabs (Original / Netto / Ändringar) when corrections exist
   - Add `NetRowsTable` component to render `corrected_data.rows`
   - Add `CorrectionDiffTable` component to show per-account deltas
   - Replace the old `CorrectionChainSection` with a compact `CorrectionMetaSection`
   - Reset `rowView` on voucher navigation and when entering edit mode
