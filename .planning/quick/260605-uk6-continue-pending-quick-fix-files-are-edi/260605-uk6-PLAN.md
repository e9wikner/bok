## Objective

Commit the pending fix that ensures B-series correction vouchers inherit the original voucher's date, and record a brief summary.

**Purpose:** Swedish accounting compliance (BFL/BFNAR) requires correction vouchers to be dated to the original period. The current code was using `datetime.now().date()` (or `now.date()`), which could place corrections in the wrong period.

**Output:** Committed fix + `.planning/quick/260605-uk6-continue-pending-quick-fix-files-are-edi/260605-uk6-SUMMARY.md`

## Context

The working tree already contains the correct changes in two files:

- `repositories/voucher_repo.py`: In `create_correction_voucher`, two occurrences of `now.date()` changed to `original.date`
- `services/ledger.py`: In `suggest_correction_voucher`, `datetime.now().date()` changed to `original.date`

These changes ensure that when a B-series correction voucher is created, it carries the same date as the original voucher being corrected.
