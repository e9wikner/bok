# Phase 04 Plan 03: Fix README Deployment Routing

<objective>
Update README.md so deployment users start from the canonical LAN-first DEPLOYMENT.md route without stale status or broken links.
</objective>

## Objective

- **What:** Update `README.md` so deployment users see the correct quick path and canonical guide, without stale phase status or broken LAN-doc links.
- **Why:** README is the first entry point; conflicting first steps make the deployment guide less useful.
- **Output:** `README.md` satisfies `DOCS-01` and routes Phase 4 deployment users to the LAN-first `DEPLOYMENT.md`.

<threat_model>
README routing can create unsafe behavior if it advertises `admin / admin`, stale phase status, or missing docs as a production deployment path. The README should avoid suggesting default credentials are acceptable for real use and should point to `DEPLOYMENT.md` for secret replacement and verification.
</threat_model>
