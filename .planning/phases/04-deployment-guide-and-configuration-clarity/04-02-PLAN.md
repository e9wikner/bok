# Phase 04 Plan 02: Align the Production Environment Example

<objective>
Align .env.production.example with the LAN deployment defaults and optional public-domain settings documented in DEPLOYMENT.md.
</objective>

## Objective

- **What:** Update `.env.production.example` comments and grouping so it matches the LAN-first deployment guide and separates optional public-domain settings.
- **Why:** Owners should be able to create `.env.production` safely without inferring which variables belong to LAN deployment versus public HTTPS.
- **Output:** `.env.production.example` becomes a clear copy template for `CONF-01`, `CONF-02`, `CONF-03`, `CONF-04`, and `DOCS-03`.

<threat_model>
The main risk is a user copying unsafe placeholder secrets or setting public-domain variables for a LAN-only deployment by mistake. The env template must make required replacement obvious and keep optional public exposure settings clearly separate.
</threat_model>
