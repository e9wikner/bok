<objective>
As a user, I want to upload one bank CSV export as bank input against an existing bank connection, so that bank source material is preserved separately from voucher source material before any agent-created voucher exists.
</objective>

<context>
This is the first Phase 2 vertical slice. It creates the durable bank-input model, CSV-only upload and download API, and file-safety tests. It does not yet import transaction rows from the CSV; that integration is Plan 02-02.
</context>

<threat_model>
**Assets:** uploaded bank CSV files, bank account/connection identifiers, source metadata, lifecycle status, filesystem paths.

**Threats:**
- HIGH: arbitrary file read if a persisted bank input path can point outside the configured storage root.
- HIGH: bank CSV is uploaded without an explicit existing bank connection, making later transaction ownership ambiguous.
- MEDIUM: non-CSV PDFs/images enter the Phase 2 bank flow even though D-02 explicitly excludes them.
- MEDIUM: repeated identical CSV uploads create duplicate pending bank work.

**Required mitigations:**
- Resolve stored paths with `Path.resolve()` and reject candidates outside the configured bank-input root before serving.
- Validate `bank_connection_id` through `BankIntegrationService.get_connection` and require `status == "active"` before creating the bank input.
- Enforce CSV-only validation by MIME type and `.csv` filename.
- Store and check SHA-256 on `bank_inputs` with a uniqueness constraint.
</threat_model>

<must_haves>
<truths>
- D-01: one bank input record represents one uploaded file.
- D-02: Phase 2 bank inputs accept CSV only, not PDFs, screenshots, or images.
- D-03: bank inputs use the lifecycle values `pending`, `processed`, and `failed`.
- D-05: uploads require a selected existing bank connection and must not create or reuse a hidden default connection.
- BANK-01: bank inputs are separate from ordinary voucher source material.
- BANK-02: bank input uploads preserve original filename, MIME type, size, SHA-256, upload timestamp, actor, and stored original file.
</truths>
</must_haves>
