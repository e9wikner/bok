<objective>
As an agent, I want to post a voucher from pending intake material through the existing ledger validation path and link the posted voucher back to the source item, so that automation remains direct while review and audit can trace every posting decision to its original evidence.
</objective>

<context>
This plan completes Phase 1 by extending the existing `POST /api/v1/agent/vouchers` path. It must not create an alternate posting path. It must preserve posted-voucher immutability and use intake links plus processing attempts for traceability.
</context>

<threat_model>
**Assets:** posted voucher records, intake source links, agent processing summaries, correction-learning traceability.

**Threats:**
- HIGH: bypassing `LedgerService` allows invalid vouchers to be posted.
- HIGH: one intake source can be processed twice, producing duplicate posted vouchers.
- MEDIUM: voucher posts successfully but traceability link is missing.
- MEDIUM: processing attempt stores incomplete actor, summary, warning/error, or voucher details.

**Required mitigations:**
- `POST /api/v1/agent/vouchers` must still call `LedgerService.create_voucher` and `LedgerService.post_voucher`.
- Intake source linkage must verify every source is pending or processing and not already linked before successful outcome.
- `voucher_intake_sources` must enforce `UNIQUE(intake_source_id)`.
- Tests must cover successful traceability and duplicate processing rejection.
</threat_model>

<must_haves>
<truths>
- D-09: recording a successful outcome must fail if the item is no longer pending or is already linked to a voucher.
- D-16: prefer intake source linkage in the agent voucher posting call, while allowing post-linking for repair/manual cases.
- D-17: Phase 1 allows one intake item per voucher.
- D-18: linking an intake item to a successfully posted voucher marks it processed atomically where possible.
- D-19: processing attempts store summary, linked voucher ID, actor, and timestamp.
- AGNT-03 agent voucher posting uses the existing voucher posting path and backend validation.
- AGNT-04 vouchers posted from intake material link back to all source items used for the decision.
</truths>
</must_haves>
