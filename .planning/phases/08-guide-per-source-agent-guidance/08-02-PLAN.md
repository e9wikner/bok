<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser form to API | User-entered guidance is sent as multipart upload or JSON update payload. |
| Detail cache to user display | React Query cache must reflect saved guidance, not stale text. |
| Voucher-source UI to bank-input UI | Shared detail route must not leak voucher-source-only controls into bank input views. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-05 | Tampering | Detail edit UI | mitigate | Disable/hide edit controls for non-editable statuses and handle backend `409` as authoritative. |
| T-08-06 | Information Disclosure | Bank input detail page | mitigate | Render guidance card only when `item.kind === "voucher_source"`. |
| T-08-07 | Repudiation | UI cache after save | mitigate | Invalidate `intake-detail` and `intake-workspace` query keys after successful save. |
</threat_model>
