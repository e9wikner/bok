<threat_model>
## Threat Model

### Threat: Public entrypoint leaks sensitive company state
- **Severity:** high
- **Mitigation:** Do not use `Depends(get_current_actor)` and do not query repositories in the entrypoint. Return static route metadata, static guardrails, and configured API version only.
- **Verification:** Test asserts entrypoint JSON has no `items`, `corrections`, `secret_key`, `api_key`, `token`, `filename`, or pending queue data.

### Threat: Agent follows unsafe or incomplete workflow
- **Severity:** medium
- **Mitigation:** Include ordered startup steps and guardrails in the payload.
- **Verification:** Test asserts startup sequence includes ping before accounting instructions, corrections before pending intake, and one-item-at-a-time processing guidance.
</threat_model>
